## 🚀 Fonctionnalités principales

### 🧠 Analyse par l'IA
- Analyse structurée des brain dumps
- Questions de clarification
- Identification des risques

### 📊 Évaluation stratégique
- 5 critères d'évaluation
- Scores d'opportunité et de faisabilité
- Justification détaillée

### 🗺️ Feuille de route interactive
- Génération automatique d'étapes
- Checklist interactive
- Suivi de progression

### 📈 Tableau de bord visuel
- Gestion centralisée des idées
- Visualisation graphique
- Filtrage et tri

### 🤖 Priorisation par l'IA
- Comparaison d'idées
- Classement automatique
- Justification de type capital-risqueur

## 🛠️ Technologies utilisées

- **Frontend** : React 19, TypeScript, Vite
- **IA** : Google Gemini API
- **Styling** : CSS moderne
- **État** : Context API React
- **Stockage** : LocalStorage

## 📋 Prérequis

- Node.js 18+
- Clé API Google Gemini
- Navigateur moderne
