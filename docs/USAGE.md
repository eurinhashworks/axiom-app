# Guide d'Utilisation - AXIOM

## Introduction

AXIOM est votre co-pilote stratégique pour transformer vos idées d'entreprise en plans d'action concrets. Ce guide vous accompagne dans l'utilisation de toutes les fonctionnalités de l'application.

## Premiers pas

### 1. Créer votre première idée

1. **Accédez au tableau de bord** : L'application s'ouvre sur le tableau de bord principal
2. **Cliquez sur "Nouvelle idée"** : Bouton bleu en haut à droite
3. **Saisissez un titre** : Donnez un nom descriptif à votre idée
4. **Confirmez** : Cliquez sur "Créer l'idée"

### 2. Saisir votre brain dump

1. **Sélectionnez votre idée** : Cliquez sur la carte de votre idée
2. **Accédez à la saisie** : Vous arrivez sur la page de saisie
3. **Décrivez votre idée** : Dans la zone de texte, décrivez :
   - Le problème que vous résolvez
   - Votre solution
   - Votre public cible
   - Ce qui vous différencie
4. **Lancez l'analyse** : Cliquez sur "Analyser avec l'IA"

## Workflow complet d'analyse

### Étape 1 : Analyse par l'IA

L'IA analyse votre brain dump et génère :

- **Résumé** : Synthèse concise de votre idée (1-3 phrases)
- **Questions de clarification** : 3-5 questions pour affiner votre pensée
- **Risques potentiels** : 3-5 défis à considérer

**Actions possibles :**
- Lire attentivement l'analyse
- Répondre mentalement aux questions
- Considérer les risques mentionnés
- Passer à l'évaluation

### Étape 2 : Évaluation stratégique

L'IA évalue votre idée sur 5 critères (scores de 1 à 10) :

#### Critères d'opportunité
- **Urgence du problème** : À quel point le problème est-il pressant ?
- **Taille du marché** : Quelle est la taille et l'accessibilité du marché ?
- **Avantage concurrentiel** : Quel est le potentiel d'avantage unique ?

#### Critères de faisabilité
- **Alignement personnel** : À quel point l'idée correspond à vos compétences ?
- **Faisabilité technique** : Quelle est la difficulté technique de construction ?

**Scores calculés :**
- **Score d'opportunité** : Moyenne des 3 critères d'opportunité
- **Score de faisabilité** : Moyenne des 2 critères de faisabilité

**Actions possibles :**
- Analyser les scores détaillés
- Comprendre les forces et faiblesses
- Passer à la feuille de route

### Étape 3 : Feuille de route

L'IA génère 5-7 étapes actionnables :

1. **Étapes de validation** : Valider l'idée avant de construire
2. **Étapes de construction** : Développer le produit minimum viable
3. **Étapes de lancement** : Mettre sur le marché

**Actions possibles :**
- Lire chaque étape attentivement
- Cocher les étapes terminées
- Suivre la progression
- Exporter le plan complet

## Tableau de bord

### Vue d'ensemble

Le tableau de bord centralise toutes vos idées avec :

- **Cartes d'idées** : Vue compacte de chaque idée
- **Scores visuels** : Barres de progression pour opportunité/faisabilité
- **Statuts** : Indicateur de progression (Brouillon, Analysé, etc.)
- **Dates** : Quand l'idée a été créée

### Actions sur les idées

#### Sélectionner une idée
- Cliquez sur une carte pour ouvrir la session d'analyse
- Utilisez la vue graphique pour sélectionner visuellement

#### Supprimer une idée
- Cliquez sur l'icône de suppression (🗑️)
- Confirmez la suppression

#### Filtrer et trier
- **Filtre par titre** : Tapez dans la barre de recherche
- **Tri par score** : Cliquez sur "Trier par score"
- **Tri par date** : Cliquez sur "Trier par date"

### Vue graphique (Matrice stratégique)

La vue graphique positionne vos idées sur :
- **Axe X** : Faisabilité (0-10)
- **Axe Y** : Opportunité (0-10)

**Quadrants :**
- **Haut-droite** : Idées prioritaires (haute opportunité, haute faisabilité)
- **Haut-gauche** : Idées à développer (haute opportunité, faible faisabilité)
- **Bas-droite** : Idées de commodité (faible opportunité, haute faisabilité)
- **Bas-gauche** : Idées à éviter (faible opportunité, faible faisabilité)

## Fonctionnalités avancées

### Priorisation par l'IA

Comparez plusieurs idées évaluées :

1. **Sélectionnez les idées** : Cochez les idées à comparer
2. **Lancez la priorisation** : Cliquez sur "Prioriser avec l'IA"
3. **Analysez les résultats** : L'IA classe les idées par priorité
4. **Lisez la justification** : Comprendre pourquoi une idée est prioritaire

### Exportation

Exportez le dossier complet d'une idée :

1. **Ouvrez l'idée** : Sélectionnez l'idée à exporter
2. **Accédez à l'export** : Cliquez sur l'icône d'export (📤)
3. **Choisissez le format** : Markdown (recommandé)
4. **Téléchargez** : Le fichier est généré et téléchargé

**Contenu de l'export :**
- Titre et description de l'idée
- Analyse complète (résumé, questions, risques)
- Scores d'évaluation détaillés
- Feuille de route complète
- Statut des étapes

## Conseils d'utilisation

### Pour des idées de qualité

1. **Soyez spécifique** : Plus votre brain dump est détaillé, meilleure est l'analyse
2. **Incluez le contexte** : Mentionnez votre expérience, le marché, la concurrence
3. **Soyez honnête** : L'IA est plus précise avec des informations réalistes

### Pour maximiser l'efficacité

1. **Utilisez les questions de clarification** : Elles révèlent des aspects importants
2. **Analysez les scores** : Comprenez pourquoi certains scores sont faibles
3. **Suivez la feuille de route** : Les étapes sont conçues pour maximiser vos chances de succès

### Pour la prise de décision

1. **Comparez visuellement** : Utilisez la matrice stratégique
2. **Priorisez régulièrement** : L'IA peut vous aider à choisir entre plusieurs idées
3. **Documentez vos décisions** : Exportez et archivez vos analyses

## Cas d'usage courants

### Validation d'idée

**Objectif** : Vérifier si une idée vaut la peine d'être poursuivie

**Processus** :
1. Créez l'idée et saisissez un brain dump détaillé
2. Analysez les scores d'évaluation
3. Si les scores sont faibles, considérez les questions de clarification
4. Décidez de poursuivre ou d'abandonner

### Comparaison d'idées

**Objectif** : Choisir entre plusieurs idées concurrentes

**Processus** :
1. Créez et analysez plusieurs idées
2. Utilisez la priorisation par l'IA
3. Comparez les feuilles de route
4. Prenez une décision éclairée

### Planification de lancement

**Objectif** : Préparer le lancement d'une idée validée

**Processus** :
1. Suivez la feuille de route étape par étape
2. Cochez les étapes terminées
3. Adaptez le plan selon vos contraintes
4. Utilisez l'export pour partager avec votre équipe

## Dépannage

### L'analyse ne se lance pas

**Causes possibles :**
- Clé API Gemini manquante ou invalide
- Problème de connexion internet
- Quota API dépassé

**Solutions :**
- Vérifiez votre fichier `.env`
- Vérifiez votre connexion
- Attendez le renouvellement du quota

### Les scores semblent incorrects

**Causes possibles :**
- Brain dump trop vague
- Informations contradictoires
- Biais dans la description

**Solutions :**
- Enrichissez votre brain dump
- Soyez plus spécifique
- Relancez l'analyse

### La feuille de route n'est pas adaptée

**Causes possibles :**
- Contexte spécifique non mentionné
- Contraintes particulières non prises en compte

**Solutions :**
- Adaptez les étapes à votre situation
- Utilisez la feuille de route comme base
- Personnalisez selon vos besoins
